## 🚀 How to View & Deploy

### Option 1: Open Directly in Any Web Browser
Double-click `index.html` in Windows Explorer to open and preview the site in Google Chrome, Microsoft Edge, Firefox, or Safari. All assets use relative paths.

### Option 2: Deploy to Free Static Hosting
The project is 100% static and requires zero build tools:
- **Netlify**: Drag and drop the `Projects` folder into [Netlify Drop](https://app.netlify.com/drop).
- **Vercel**: Run `vercel` or link a GitHub repository.
- **GitHub Pages**: Push the files to a repository and enable GitHub Pages on the `main` branch.
- **cPanel / Apache / Nginx**: Upload the contents directly to `public_html`.
